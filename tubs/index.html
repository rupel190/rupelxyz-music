Obsidian plugin

TUBS Renderer

Guitar TABS for drums. TUBS is an existing concept. The plugin enables you to render it nicely and play your patterns inside Obsidian. Try it right here: pick an example, press play, then edit the text.

Reading it

Each row is an instrument and each column is one slice of time. A mark in a box means hit here. If you can read a step sequencer, you can read this.

  • .rest
  • xhit
  • Xaccent
  • gghost note
  • oopen hi-hat
  • _hold the last note
  • F1bass pitch

Get the plugin

It isn't in Obsidian's community plugin list yet. Download main.js, manifest.json and styles.css from the latest release on GitHub, put them in <vault>/.obsidian/plugins/tubs-renderer/, and enable TUBS Renderer under Community plugins. The full syntax is in the README there.
